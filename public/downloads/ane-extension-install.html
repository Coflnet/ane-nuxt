Select reference prices directly

Ane Deals extension 0.3.0 lets you choose a price on an HTTPS product page and create a listing alert. Shift+click adds shipping or extras in the same currency.

Download for Chrome / Chromium · Download for Firefox

Download source and tests (includes the dependency lockfile; recorded screenshots, browser profiles and logs are excluded).

Chrome / Chromium

  1. Download and unzip the Chrome package.
  2. Open chrome://extensions and enable Developer mode.
  3. Choose Load unpacked and select the extracted folder containing manifest.json.
  4. Pin Ane Deals in your extensions menu.

Firefox

This download is an unsigned development extension. Firefox loads it temporarily until the browser closes.

  1. Download and unzip the Firefox package.
  2. Open about:debugging#/runtime/this-firefox.
  3. Choose Load Temporary Add-on and select the extracted manifest.json.

Choose a reference price

  1. Open a product page and press Ane Deals in the toolbar.
  2. Choose Select a reference price on this page, then click a visible price with its currency.
  3. Optionally Shift+click shipping or another price, review the total, and choose Create alert on Ane Deals.
  4. The alert form preserves your selected price and elements. Choose Preview reference to check public server access, review your search and notifications, then save your filter.

Escape or Cancel stops selection. An ordinary click starts a new price selection.

Daily refresh requires the selected elements to remain publicly accessible to the server. Prices visible only after your sign-in can set an initial threshold, but the server cannot access that signed-in page. Missing elements or a different currency leave your existing threshold unchanged.

Only your selected prices, selectors, page title and URL enter the alert link. Cookies, page HTML and your marketplace sign-in stay in your browser. On supported marketplace listings, signing into Ane also enables explicit listing captures and price comparisons. Browser captures are labeled unverified and cannot rewrite existing server listing details or establish sale status.
